HWID Hardware Licensing

හාඩ්වෙයාර් පාදක ලයිසන් පද්ධතිය

Supervisor Authorization

සුපර්වයිසර් අනුමැතිය සහිත බිල් කිරීම

තොග නොමැති විට Supervisor මුරපද මඟින් පමණක් බිල් කිරීමේ පහසුකම.

PO Approval Workflow

ඇණවුම් කළමනාකරණය (PO Module)

Multi-stage PO processing with Draft, Processed, and Approved workflows. Access restricted via `po_approve_access` permission flags.

අනුමැතිය ලබාගත් පසු පමණක් GRN වෙත ඇතුළත් කළ හැකි PO පද්ධතිය.

GRN & Auto Unit Conversion

භාණ්ඩ ලබාගැනීම සහ ස්ටොක් කිරීම

Auto-import PO details into GRN. Dynamic calculations automatically convert whole package quantities into sellable individual Base Units.

පැකේජ Unit බවට auto-convert කර ප්‍රධාන ස්ටොක් එකට ඇතුළත් කිරීම.

Dynamic Expiry Control

Toggle Expiry tracking on or off in System Settings to dynamically adjust GRN layout columns for food/pharmaceutical or general hardware stores.

ව්‍යාපාරයේ ස්වභාවය අනුව Expiry Column එක පෙන්වීම හෝ සැඟවීම.

User Operating Manual

How to Operate the System (Step-by-Step)

පද්ධතිය පියවරෙන් පියවර භාවිතා කරන ආකාරය පිළිබඳ සම්පූර්ණ උපදෙස් මාලාව

01

System Login (පද්ධතියට ප්‍රවේශ වීම)

Launch the desktop application. Enter your assigned Username and Password in the compact login prompt. Upon validation, the software automatically maximizes to full-screen desktop layout.

💡 සිංහල උපදෙස්: Software එක Open කර ඔබගේ Username සහ Password ලබාදී Login වන්න. Login වූ සැනින් App එක auto-maximize වී Dashboard එක පෙන්වයි.
02

POS Billing & Negative Stock Authorization (බිල් කිරීම)

Scan item barcodes or search by name. If an item has 0 stock, an Authorization Modal will pop up requesting a Supervisor’s credentials. Once approved, the transaction completes and logs the authorization event.

💡 සිංහල උපදෙස්: භාණ්ඩ Scan කර Cart එකට එකතු කරන්න. Stock එක 0 නම් Supervisor Password ඉල්ලන Popup එකක් එයි. Supervisor මුරපදය ඇතුළත් කර බිල් කිරීම සිදු කළ හැක.
03

Creating & Approving PO (ඇණවුම් සෑදීම සහ අනුමැතිය)

Open PO Module -> Click "Create New PO". Select Supplier, add items, set Package Cost and Quantities. Click "Save PO" (Draft), then "Process PO". An authorized user with `po_approve_access` must click "Approve PO" before it can be converted to GRN.

💡 සිංහල උපදෙස්: PO Module එකෙන් "Create New PO" තෝරන්න. Supplier සහ භාණ්ඩ ඇතුළත් කර Save කර Process කරන්න. Manager/Supervisor විසින් Approve කළ පසු GRN සෑදීමට සුදුසු වේ.
04

GRN Processing & Auto Stock Conversion (භාණ්ඩ බාරගැනීම)

Open GRN Module -> Click "Create New GRN" -> Enter Approved PO Number and click "Load PO". Verify items, costs, selling prices, and Expiry Dates. Click "Process GRN" to automatically convert Package Qty to Base Units and add to inventory.

💡 සිංහල උපදෙස්: GRN Module එකේ "Create New GRN" ඔබා Approved PO No එක දී Load කරන්න. සියලු විස්තර පරීක්ෂා කර "Process GRN" ලබාදෙන්න. Packets ස්වයංක්‍රීයව Base Units බවට හැරී Stock එකට එකතු වේ.
05

Database Backup & Admin Control (ඇඩ්මින් පාලනය)

Under Admin Control, administrators can view Hardware License Key status, enter new extension keys, or create timestamped database backups (`.db` files) to secure system data against computer failures.

💡 සිංහල උපදෙස්: Admin Control එක හරහා License කල්පිරීම් පාලනය කිරීම සහ ඩේටාබේස් එක පරිගණකයට Backup (Download) කර සුරක්ෂිතව තබා ගැනීම සිදුකළ හැක.
